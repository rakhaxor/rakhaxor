## Security tooling

I also test how apps hold up from the outside, and I write the tools I need for it. Both of these are for authorized testing.

- **[burp-redirect](https://github.com/rakhaxor/burp-redirect)**: Android app that sends a rooted device's HTTP and HTTPS traffic to Burp Suite through iptables. Flutter apps ignore the system proxy, this gets their traffic into Burp anyway. Kotlin.
- **[depconf](https://github.com/rakhaxor/depconf)**: command-line tool that finds npm packages a company's JavaScript refers to but nobody has registered on npmjs.com, the opening for a dependency confusion attack. It reads live sites, local bundles, HAR files and GitHub organizations. Python.
